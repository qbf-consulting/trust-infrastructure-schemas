# Stewardship and provenance

Trust Infrastructure Schemas (TIS) is maintained by **Sankarshan Mukhopadhyay** (`sankarshan@qbfconsulting.digital`) and stewarded by **QBF Consulting LLP**.

The canonical QBF repository is https://github.com/qbf-consulting/trust-infrastructure-schemas.

This repository is a GitHub fork with upstream lineage from `archetech/schemas`. Upstream copyright and MIT licensing are retained. QBF stewardship and current maintenance do not erase or replace upstream authorship or third-party contribution history.

TIS is authoritative for its portable machine-readable contracts, project-local identifiers, compatibility declarations and validation behavior. TSMM remains authoritative for canonical semantics. TGA remains authoritative for its own executable governance compositions and implementation artifacts.

Historical schema identifiers and immutable evidence are not silently rewritten merely because repository stewardship or publication location changes. Any identifier migration requires an explicit compatibility and versioning decision.

Use [`CITATION.cff`](../CITATION.cff) for citation of the current maintained project and [`STEWARDSHIP.md`](../STEWARDSHIP.md) for the repository-level provenance statement.

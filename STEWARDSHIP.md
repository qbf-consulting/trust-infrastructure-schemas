For citation of the current TIS project, use `CITATION.cff`. Citation metadata identifies the current maintained project and must be read together with the repository's fork lineage, license, and commit history when attribution of particular code or artifacts matters.

## Authority boundary

QBF Consulting LLP stewardship means that QBF hosts and governs the current TIS project repository and its project-local release process. It does not imply ownership of upstream Archetech authorship, external specifications, TSMM canonical semantics, TGA project-local compositions, or third-party contributions.

Historical schema identifiers and immutable evidence are not silently rewritten merely because repository stewardship or publication location changes. Identifier migrations, where necessary, require explicit compatibility and versioning decisions.

# Governance

Trust Infrastructure Schemas (TIS) is maintained by Sankarshan Mukhopadhyay and stewarded by QBF Consulting LLP. The canonical project repository is `qbf-consulting/trust-infrastructure-schemas`.

TIS maintainers control project-local canonical schema identifiers, artifact families, compatibility policy, deprecation, releases, and emergency corrections. Schema changes require validation, compatibility analysis, examples, and documentation. TSMM remains authoritative for canonical semantics; TGA remains authoritative for its implementation packages.

TIS is a fork with upstream Archetech provenance. QBF stewardship does not rewrite upstream authorship, copyright, license obligations, third-party contribution history, or immutable historical evidence. See `STEWARDSHIP.md` and `LICENSE`.
